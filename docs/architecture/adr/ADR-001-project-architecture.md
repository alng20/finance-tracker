# ADR-001: Project Architecture

## Status

Accepted

## Context

Finance Tracker is a multi-user family finance management application.

The project should be maintainable, testable and scalable.

## Decision

Use Clean Architecture.

The system will be divided into:

- Domain
- Application
- Infrastructure
- API

## Consequences

Benefits:
- Clear separation of responsibilities
- Easier testing
- Better maintainability
